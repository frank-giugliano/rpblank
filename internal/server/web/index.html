What's happening

rpblank watches Steam for Remote Play sessions, darkens your screens while one runs, and runs your scripts around it. Windows never sleeps the desktop itself, so a stream always starts with a live picture.

Displays

Tick a screen to darken it during sessions and after idle. Press Off, then On, before ticking: if the picture goes black but the backlight stays on, try the other off values. A screen that ignores all of them needs a command instead; see Scripts.

Scripts

Commands run at fixed points in a session, in this order. One command per line; quote paths with spaces. Each gets RPBLANK_EVENT and RPBLANK_CLIENT; output goes to hooks.log.

Session detected

The instant Steam logs a client connecting, before anything else. Pin the audio device here so Steam captures a stable one.

Wake and settle

rpblank wakes the display and waits for the link to come up.

Screens darken

Ticked displays are powered down over DDC. Add commands here for screens DDC can't reach, like a TV over HDMI-CEC or a smart plug. These also run for idle blanking.

Stream running

Runs once the screens are dark.

Screens come back

After the stream ends and the grace period passes, displays are powered on. The counterpart of the darken commands goes here.

Stream over

Runs after the screens are back, plus the delay set under Timing. Audio back to the TV lives here.

Timing and clients

How long rpblank waits at each step, and which clients it acts for.

Idle blanking

Replaces Windows' display sleep. Set Windows to Turn off display: Never and put your timeout here. The screens go dark after that long without keyboard or mouse input and wake on the next input. A running game, Big Picture with a game, a video, or a stream keeps them on, just as with Windows.

Around a session

Settle gives a woken monitor time to accept DDC. Grace absorbs the reconnects Steam does on a Wi‑Fi blip. The stop delay lets HDMI audio endpoints reappear before your audio script runs.

Clients

Leave empty to act for every client. Names are what Steam calls the device, as shown in the log.

Log

The last 80 lines of rpblank.log. Script output is in hooks.log next to it.
