What's happening

rpblank watches Steam for Remote Play sessions. While one runs it switches your screens off, moves sound to the stream, and runs your scripts; afterwards it puts everything back.

Displays

Tick the screens to switch off while a session runs. They lose signal for the session, the same way Moonlight with Vibeshine does it, and come back when it ends.

This needs Steam's virtual display turned on (Steam → Settings → Remote Play), because the desktop has to live somewhere while your screens are off. The change is never saved to Windows, so a reboot or Restore now always brings the screens back. The Off button only works during a session.

Audio

Which playback device Windows should use when a session starts and after it ends. Devices that are unplugged or whose screen is off are still listed.

When a session connects

Set this to Steam Streaming Speakers so Steam captures a stable device from the first second.

After the session ends

rpblank waits for the device to come back (a TV's audio returns a few seconds after its picture) and then switches. Previous device returns to whatever was playing before the session, unless you changed it yourself in the meantime.

Scripts

Commands run at fixed points in a session, in this order. One command per line; quote paths with spaces. Each gets RPBLANK_EVENT and RPBLANK_CLIENT; output goes to hooks.log.

Session detected

The instant Steam logs a client connecting. The connect audio device from the Audio tab is set first, then these run.

Screens darken

Ticked displays are switched off as soon as Steam's virtual display is up. Extra commands go here, for example a TV over HDMI-CEC or a smart plug.

Stream running

Runs once the session is under way.

Screens come back

After the stream ends and the grace period passes, the screens are restored. The counterpart of the darken commands goes here.

Stream over

Runs last: after the screens are back and the disconnect audio device from the Audio tab is set, plus the delay under Timing.

Timing and clients

How long rpblank waits at each step, and which clients it acts for.

Around a session

Grace absorbs the reconnects Steam does on a Wi‑Fi blip and the gap when you close one game and start another; raise it if your screens flash on between games. The stop delay only applies to your stop scripts.

Clients

Leave empty to act for every client. Names are what Steam calls the device, as shown in the log.

Log

The last 80 lines of rpblank.log. Script output is in hooks.log next to it.
